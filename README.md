## Предобработка данных для обучения модели и для построения дашборда.

### Цель
Подготовить датасеты для двух сценариев:
* `model_data` - обучение модели регрессии (`y` - `Ozone`)
* `dashboard_data` - визуализация данных

---
### Данные
Датасет: `miteshpadiya/data-cleancsv` (Kaggle)

158 строк, 10 столбцов.

Признаки: `'Unnamed: 0'` (технический), `'Ozone'`, `'Solar.R'`, `'Wind'`, `'Temp C'`, `'Month'`, `'Day'`, `'Year'`, `'Temp'`, `'Weather'`.

---
### Структура работы
#### 1. Первичная диагностика: `info`, `describe`, `nunique`, `heatmap`

#### 2. Очистка данных:
* Удалены дубликаты
* Исправлено неправильное значение месяца `'May'` на `5`
* Удалены пропуски в столбце `'Weather'` (1.9%)
* Удалены столбцы с константными значениями (`'Year'`), индексы (`'Unnamed: 0'`) и дубликат, содержащий строчные значения температуры (`'Temp C'`)

#### 3. Model_data
* Удалены строки, содержащие пропуски в целевой переменной `'Ozone'`
* Удалена колонка `'Day'`
* Данные поделены на `train` и `test` перед работой с пропусками во избежание утечки данных
* Для числовых непрерывных признаков ('`Solar.R`', `'Wind'`, `'Temp'`) до `KNNImputer` применен `StandardScaler` для стабилизации обучения модели линейной регрессии
* Использован алгоритм `KNNImputer` (n_neighbors=5,
    weights='distance'), `fit_transform` на `train_X` и `transform` на `test_X`
* Для категориальных данных (`'Weather'`, `'Month'`) применен `One-Hot-Encoder`
* В папках `./train/` и `./test/` cохранены соответствующие файлы: `train_X.csv`, `train_y.csv`, `test_X.csv`, `test_y.csv`

#### 4. Dashboard_data
* Сохранены все изменения из пункта `2. Очистка данных`
* `One-hot-encoder` и `Imputer` не применены, пропуски остались как есть, категориальные данные оставлены как есть.
* Данные сохранены в папку `'./dashboard'`, название файла `'dashboard_data.csv'`
